# Portfolio Website

My personal portfolio site, built from scratch with HTML, CSS, and JavaScript. It covers who I am, my skills, and the projects I've built.

**Live site:** https://icastle26.github.io/portfolio-website/

## Features
- Sticky navigation with smooth scrolling between sections
- Responsive layout using CSS Grid and Flexbox, so it works on phones and desktops
- Project cards linking to live demos and source code
- Accessible focus states for keyboard users
- No frameworks or build step, just plain HTML, CSS, and JavaScript

## Tech Used
- HTML5
- CSS3 (Grid, Flexbox, media queries)
- JavaScript

## How to Run
Visit the live site above, or download this repo and open `index.html` in your browser.
